# Lawfy website

Single-page static site (`index.html`, no build step). Deployed on Netlify from this repo.

To set the booking link and contact email, edit the two constants near the bottom of `index.html`:

```js
const BOOKING_URL = "";   // e.g. "https://cal.com/lawfy/audit"
const CONTACT_EMAIL = ""; // e.g. "josh@lawfy.co"
```
